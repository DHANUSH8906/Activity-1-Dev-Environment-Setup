## Overview

This activity contains solutions to five HackerRank problems covering matrix traversal, dynamic arrays, string processing, comparison logic, and frequency counting.

## Complexity Summary

| Problem | Time Complexity | Space Complexity |
|---|---|---|
| Diagonal Difference | O(N) | O(1) |
| Dynamic Array | O(N + Q) | O(N) |
| Time Conversion | O(1) | O(1) |
| Compare the Triplets | O(N) | O(1) |
| Sparse Arrays | O(N × Q) | O(Q) |

> Note: The Sparse Arrays implementation uses direct string comparisons for each query, giving O(N × Q) time complexity.
